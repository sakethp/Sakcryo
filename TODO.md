- [x] **Profile and match preferences** — Users can create and edit a profile that specifies what they want in a match. Include display name, gender identity, short bio, genders they are interested in, and a maximum distance (50 km MVP default); represent preference as explicit gender preferences rather than inferred orientation.
- [x] **Location-gated discovery and eligible candidates** — A user must have browser/device location enabled and grant permission for a successful location read before any matches are shown; denied or unavailable location yields no match cards and a clear enable-location message. Discovery uses only geographic distance and mutually compatible stated gender preferences as matching eligibility criteria, with no other profile signal used for filtering or ranking. A candidate must fall within both users’ distance preferences; eligible candidates are ordered by distance only. Coordinates are stored privately and not exposed to other users.

A profile exposure is recorded atomically before its card is returned, so that user never sees that potential match again, including after refresh. Each viewer/candidate pair has at most one persisted swipe decision.
- [x] **Mutual matching and private chat** — A match is created only when both users have swiped right on each other. Only the two participants in that mutual match can access their one-to-one chat and its messages; unmatched users cannot chat.
